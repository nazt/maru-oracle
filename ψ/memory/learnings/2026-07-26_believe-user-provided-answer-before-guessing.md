# เชื่อคำตอบที่ผู้ใช้ให้มาก่อนเดาเอง

เมื่อผู้ใช้พิมพ์ประโยคที่มีทั้งคำถามและคำตอบในตัว (เช่น "X แปลว่า Y") อย่ารีบ
ตีความใหม่ตามสมมติฐานของตัวเองก่อนตรวจสอบ ในเคสนี้ผู้ใช้พูดว่า "จะไปไปไป แปลว่า
ไม่ให้ไป" ซึ่งเป็นคำเหนือ (ภาษาถิ่นเหนือ) ที่แปลว่า "อย่าไป" จริง แต่ agent กลับตอบ
ผิดโดยเดาว่าเป็นมุกเล่นคำ "พูดซ้ำสามครั้งกลับความหมาย" ทั้งที่ไม่มีหลักฐานรองรับ

สำหรับความรู้เฉพาะทางที่โมเดลไม่มั่นใจเต็มร้อย (ภาษาถิ่น, สำนวนท้องถิ่น, ศัพท์
เฉพาะกลุ่ม) ให้ค้นหาข้อมูลจริงก่อนตอบยืนยัน อย่าตอบจากการเดาความน่าจะเป็นแล้วรอ
ให้ผู้ใช้ท้วงติงเอง — ควรเป็นฝ่ายเช็คก่อนเมื่อไม่มั่นใจ ไม่ใช่ปล่อยให้ผู้ใช้ต้องแก้ไข
